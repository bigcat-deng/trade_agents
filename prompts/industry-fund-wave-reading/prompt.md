# 背景：这张图怎么读

## 颜色是什么（不是热度，也不是绝对成交额）
- 每个行业：成交额取 log1p，再相对**该行业自己**近 {{ lookback }} 个交易日历史做滚动 z（基线严格过去，不含当日）。
- 显示分 = 0.5 + 0.5·tanh(z / 1.5)，约在 0～1：
  - ~1：相对自身明显放量
  - ~0：相对自身明显缩量
  - ~0.5：接近自身常态
- 这是自身历史对照，不是截面谁成交额最大；不要写成「资金流入 / 主力进场」。

## 坐标与水波（主题热度水面页嵌入版）
- 横轴：与上方行业短热同一叶序冻结；相邻≈短热共动近，**不是**成交额共动聚类。
- 相邻列插值只为连续色场；点名只用真实行业名，代表团块即可。
- 进深为交易日。优先看红带占位、迁移与扩散，不要只盯截止日最红一列。
- 水波：竖向长红≈持续异常放量；红带左右扩/缩≈放量簇扩散或收窄；变冷≈回到常态或缩量。

## 叠加层
- 截止日顶红字：自身异常最高 Top5；蓝字：自身异常最低 Top5。
- 本层没有 MACD / 分型 / 收益±2σ / 中证500 线。

## 读法优先级
1. 先按叶序辨「放量团 / 缩量团」，看是否连片。
2. 再看扩散：放量核向相邻叶序变宽 = 扩散加大；只剩孤立尖峰或相邻列回常态 = 扩散减弱。
3. 长红占位、二波回补、单日脉冲要区分；脉冲不要写成持续占位。
4. 与短热对照（若数据有 hotness）：热高量弱 / 量高热弱只作结构观察，不推因果。
