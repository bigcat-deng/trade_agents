# 背景：这张图怎么读

## 热度是什么
- 底层短热 heat_short：收益平滑 → 当日截面排名 → 再短窗平滑；原始值越小越热。
- 表里的截止热度、中间热度、Δ 是 hotness（约 0～1，越大越热）。读图以团块与时间形态为主，不要堆砌单个行业的数值。

## 坐标与水波
- 横轴：窗口内短热轨迹聚类叶序，整窗固定；相邻≈共动近，不是产业链上下游。
- 相邻列插值只为连续色场；点名只用真实行业名，代表团块即可。
- 进深为交易日。优先看红带占位、迁移与扩散，不要只盯截止日最热一列。
- 水波：竖向长红≈持续占位；红带左右扩/缩≈热簇扩散或收窄；变冷≈热核降温；大片同色≈截面共振。

## 叠加层（与颜色热度独立）
- 黑/白细线：收益相对自身近 100 日波动 ±2σ；顶上红/绿字：截止日正超/负超。
- 橙×/蓝×：MACD 上穿/下穿；红/黑圆点：顶/底分型。
- 右侧实线：中证500日收益；虚线：成交量（已对齐）。

## 读法优先级
1. 先按叶序辨「升温团 / 降温团」，看是否连片。
2. 再看扩散：热核向相邻叶序变宽 = 扩散加大；只剩孤立尖峰或相邻列转冷 = 扩散减弱。
3. 长红占位、二波回补、单日脉冲要区分；脉冲不要写成主线。
4. 冲击标记只在与团块叙事明显同向/背离时提一句。

## 写作纪律
- 禁止罗列各行业 hotness / Δ 数值；最多点 2～4 个代表性行业名指代团块。
- 不用「主力」「机构抢筹」等无法从数据推出的话。
- 不给买卖指令，不谈仓位，不预测涨跌幅。
- 全文精炼：总篇幅宜短，每节几句即可；「未来」必须写清扩散加大→续热、扩散减弱→趋冷的条件句。
