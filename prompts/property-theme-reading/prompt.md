## 页面在回答什么

三层问题，一次说清：
1）群 A（建筑链：装配式建筑/建筑节能）内部热度是否一致；群 A 与群 B（基建：一带一路/高铁）是否一起动；卫星（物业管理、水泥概念）是否独立爆发。
2）近 60 个交易日，各概念价格相对中证500是强是弱。
3）热度变化与相对指数的价格表现，是一致还是矛盾，像什么市场信号。

读法提醒：本页看建筑↔基建政策周期结构。库中无独立「房地产」概念，成员是建筑链与基建代理，不是行业地产本身。先看建筑链抱团，再看与一带/高铁是共振还是分叉；群 B 内部重叠弱于群 A，不要强行把群 B「同热」写成主结论。物业、水泥只作卫星。

## 读数规则

热度：
- 短热是名次的 5 日平滑，数字越小越热；分位 0=当日全市场概念中最热，1=最冷。
- 热度窗口约 20 个交易日。窗口变热 = 窗口起点短热 − 截止日短热；大于 0 表示变热；窗口Δ数字仍在数据里，但只作背景。
- 徽章「同热/同冷/同向」按近端（近 k 日短热斜率）判定，与图上近端升降温一致；若近端同升而整窗仍偏冷，徽章写「同热」并可注「整窗仍同冷」。
- 近端趋势亦见数据块「近端趋势」与上图序列末段：分位变小=升温，分位变大=降温（图上上行朝向 0=升温）。
- 近端与整窗方向冲突时：定性总领与 A↔B 同热/同冷一律跟徽章近端方向；整窗只作背景一句，禁止把整窗变冷写成「当前仍在降温」或「同冷」同向。
- 徽章规则摘要：|窗口变热|≤5 为平坦；「仅龙头热」优先于「同热」；方向对立或分位离散明显拉大则「拆开」；A↔B 先看方向对打；卫星分位≤0.10 或超额变热则「爆发中」。

价格：
- 迷你 K 为近 60 个交易日 OHLC；灰底中证500是按「本图」高低对齐后的走势，不是指数绝对点位。
- 数据里已给出概念收益率、中证500收益率、超额（概念收益 − 指数收益），单位为百分比。不要讨论中证500点位本身。
- 热度窗口与价格窗口长度不同，写的时候分开说，不要混成同一个窗口。

## 信号词（组合判断时优先用这些，可少用不可乱造）

- 变热 + 超额为正 → 热度有价格确认
- 变热 + 超额为负或接近 0 → 热在涨、价未跟上（或弱于中证500）
- 变冷或平稳 + 超额为正 → 价强于指数，但注意力未集中
- 变热 + 与指数涨跌接近（超额接近 0）→ 更像贝塔抬升，不像独立主线
- 群内热度拆开 + 只有龙头超额明显 → 叙事收窄到龙头（如只剩装配式或只剩建筑节能）
- 建筑链热、基建冷（或相反）→ 建筑↔基建分叉 / 政策叙事切换
- 建筑链与基建同热 + 超额同向 → 更像地产基建政策共振
- 物业管理/水泥爆发 + 群A未同热 → 物业或建材脉冲，尚未回传建筑链
