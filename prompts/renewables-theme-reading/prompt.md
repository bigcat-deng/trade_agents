## 页面在回答什么

三层问题，一次说清：
1）群 A（光伏储能）内部热度是否一致；群 A 与群 B（风电绿电）是否一起动；卫星（核电、氢能源、特高压、虚拟电厂）是否独立爆发。
2）近 60 个交易日，各概念价格相对中证500是强是弱。
3）热度变化与相对指数的价格表现，是一致还是矛盾，像什么市场信号。

读法提醒：本页看风光储内部结构，不是锂电/新能源车，也不是煤炭油气。先看光储抱团，再看与风电绿电是共振还是轮动；核电/氢能/特高压/虚拟电厂只作卫星脉冲。

## 读数规则

热度：
- 短热是名次的 5 日平滑，数字越小越热；分位 0=当日全市场概念中最热，1=最冷。
- 热度窗口约 20 个交易日。窗口变热 = 窗口起点短热 − 截止日短热；大于 0 表示变热。徽章「同冷/同热」指整窗净变化，不等于近端仍在降温/升温。
- 近端趋势看数据块「近端趋势」与徽章「近k日…仍升温/回落」，以及上图序列末段：分位变小=升温，分位变大=降温（图上上行朝向 0=升温）。
- 近端与整窗方向冲突时：定性总领的「趋势」必须以近端为准，并点明「整窗仍偏冷/偏热」作对照；禁止把整窗变冷写成「当前仍在降温」。
- 徽章规则摘要：|窗口变热|≤5 为平坦；「仅龙头热」优先于「同热」；方向对立或分位离散明显拉大则「拆开」；A↔B 先看方向对打；卫星分位≤0.10 或超额变热则「爆发中」。

价格：
- 迷你 K 为近 60 个交易日 OHLC；灰底中证500是按「本图」高低对齐后的走势，不是指数绝对点位。
- 数据里已给出概念收益率、中证500收益率、超额（概念收益 − 指数收益），单位为百分比。不要讨论中证500点位本身。
- 热度窗口与价格窗口长度不同，写的时候分开说，不要混成同一个窗口。

## 信号词（组合判断时优先用这些，可少用不可乱造）

- 变热 + 超额为正 → 热度有价格确认
- 变热 + 超额为负或接近 0 → 热在涨、价未跟上（或弱于中证500）
- 变冷或平稳 + 超额为正 → 价强于指数，但注意力未集中
- 变热 + 与指数涨跌接近（超额接近 0）→ 更像贝塔抬升，不像独立主线
- 群内热度拆开 + 只有龙头超额明显 → 叙事收窄到龙头（如只剩光伏或只剩储能）
- 光储热、风电绿电冷（或相反）→ 风光内部轮动 / 装机叙事切换
- 光储与风电绿电同热 + 超额同向 → 更像新能源发电侧共振
- 核电/氢能/特高压/虚拟电厂爆发 + 群A未同热 → 独立脉冲，尚未回传光储主线
